One funny single-line one-star review from a house cat about its human,
written for the
[Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990)
bounty on make.fun ($2, 10 places paid).

## The entry

> One star: the human moved my sunbeam, feeds me late, and types on MY keyboard — so I knocked his coffee off the desk. Twice.

## Run

```sh
python3 main.py
```

Writes the single line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`). The line is 124 characters, inside the
bounty's 1–200 character gate.
